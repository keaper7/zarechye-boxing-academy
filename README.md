# Zarechye Boxing Academy

Сайт боксёрского зала Айдамира Тлинова. Next.js 16 (App Router) + TypeScript +
Tailwind v4 + Motion + Lenis.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # статический сайт в out/
```

## Публикация

Сайт живёт на GitHub Pages: **https://keaper7.github.io/zarechye-boxing-academy/**

Публикуется сам: любой пуш в `main` запускает
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml), который
собирает проект и выкладывает папку `out/`. Ничего собирать и коммитить
руками не нужно — только `git push`.

Разово в настройках репозитория должно быть выставлено
**Settings → Pages → Source: GitHub Actions**.

Почему статический экспорт (`output: 'export'` в `next.config.ts`):
GitHub Pages не запускает Next.js, он отдаёт готовые файлы. Отсюда же
`basePath` — сайт лежит не в корне домена, а в подпути с именем
репозитория. В dev-режиме `basePath` отключён, поэтому локально всё
по-прежнему на `localhost:3000` без подпути.

### Свой домен

Когда у клиента появится домен: заменить `SITE_URL` в `src/content.ts`,
убрать `basePath` из `next.config.ts` и добавить домен в
Settings → Pages → Custom domain.

## Где что менять

**Весь текст, цифры и ссылки — в одном файле: [`src/content.ts`](src/content.ts).**
В JSX нет ни одного захардкоженного факта. Каждое поле там помечено:

- `VERIFIED` — подтверждено открытыми источниками (био Instagram-аккаунтов);
- `TODO` — данных нет, ждём от клиента.

### Что подтверждено и откуда

| Факт | Источник |
|---|---|
| Название, тренер, «взрослые и дети», «−5–10 кг за 2 месяца», «первая тренировка бесплатно», слово «БОКС» в директ | био [@zarechye_boxing_academy](https://www.instagram.com/zarechye_boxing_academy/) |
| МС России по боксу, финалист чемпионата России 2018, professional record 1:0, Threads | био [@aydamir_tlinov](https://www.instagram.com/aydamir_tlinov/) |

Ничего сверх этого на сайте не утверждается. Придуманных отзывов, «100+ учеников»
и «работаем с 2015 года» здесь нет намеренно — такие цифры проверяются
первым же звонком.

### Чего ждём от клиента

| Что | Где включить |
|---|---|
| Цены на абонементы | `pricing` → `enabled: true` + `items` |
| Портрет тренера | `coach.portrait: '/coach.jpg'` — пока там графическая панель |
| Видео тренировок | обещано отдельно, места под него ещё нет |
| Точка на карте | `contact.place.mapUrl` — сейчас там поиск по адресу, а не готовая точка |
| Реальный домен | `SITE_URL` в начале `content.ts` |

Уже получено и на сайте: адрес и телефон (`contact.place`), расписание
(`schedule`), фотографии зала (`gallery`).

Секции с `enabled: false` не рендерятся вовсе — пустых блоков «уточняйте»
на странице не появится.

### Как подставить фотографии

Фотографии зала — от заказчика напрямую. Снято на телефон, 960×1280, свет
люминесцентный: кадры честные, но «дежурные» по цвету, а оранжево-синие маты
на них спорят с тёмной вёрсткой. Поэтому перед публикацией они проходят через
скрипт, а не кладутся в `public/` как есть.

```bash
node scripts/prepare-photos.mjs "<папка с исходниками>"   # обработать и разложить
node scripts/gallery-entries.mjs                          # напечатать блок для content.ts
node scripts/contact-sheet.mjs                            # склеить лист, чтобы оценить подборку
```

`prepare-photos.mjs` делает лёгкий контраст и небольшое приглушение цвета,
кладёт в `public/gym/` по два размера (`-480` и `-960`) и печатает крошечную
размытую заглушку в base64. Отбор кадров — руками, список в начале скрипта.

Почему два размера: на статическом экспорте `next/image` не режет картинки
на лету (`images.unoptimized`), поэтому `srcset` собран вручную в `Gallery.tsx`.
Без этого телефон качал бы 1,7 МБ десктопных файлов вместо 0,6 МБ.

Пути к файлам в `public/` там пишутся с префиксом `NEXT_PUBLIC_BASE_PATH`
(объявлен в `next.config.ts`): сайт живёт в подпути, и обычный `<img src="/…">`
без префикса ловил бы 404 — в отличие от `next/image`, который подставляет его сам.

Портрет тренера — отдельная история: он подставляется в `coach.portrait`,
и `MediaSlot` сам заменит графическую панель на `next/image`.

## Структура

```
src/
  content.ts              единственный источник фактов
  app/
    layout.tsx            шрифты, метаданные, прелоадер, шапка
    page.tsx              порядок секций
    opengraph-image.tsx   картинка для соцсетей (генерируется)
    globals.css           токены палитры и типографики
  components/
    HeroCanvas.tsx        мешок на цепи: маятник, реакция на курсор, удар по клику
    Reveal.tsx            единственная reveal-обёртка на весь сайт
    MediaSlot.tsx         место под фото
    Ornament.tsx          фирменный мотив «угол ринга»
    ...
  lib/
    SmoothScroll.tsx      Lenis
    usePrefersReducedMotion.ts
    useMediaQuery.ts
```

## Движение

Всё движение выключается при системной настройке «уменьшить движение»:
canvas рисует один статичный кадр, Lenis не инициализируется, лента слов стоит,
горизонтальная прокрутка шагов заменяется обычным списком, reveal схлопывается
в мгновенное появление. Проверяется в macOS: Системные настройки → Универсальный
доступ → Дисплей → Уменьшение движения.

## Доступность

- контраст приглушённого текста к фону — 9.2:1 и 4.9:1 (WCAG AA);
- FAQ на настоящих `<button>` с `aria-expanded` / `aria-controls`;
- видимый `:focus-visible` на всех интерактивных элементах;
- canvas помечен `aria-hidden`, латинский логотип продублирован
  русским названием для скринридеров.
